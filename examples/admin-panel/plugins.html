Examples / Plugins

Plugin bridge: Slim Select and Tom Select

Optional plain JavaScript select plugins for teams migrating AdminLTE plugin screens. Bootstrap remains the core interaction runtime; these plugins are loaded only on this page.

Slim Select multi-select

Slim Select keeps the native select as the source of truth and adds a compact searchable multi-select without jQuery.

Use this for compact multi-select screens where legacy admin plugins were only needed for styling and search.

Tom Select searchable select

Tom Select covers tagging, async-friendly search patterns, and keyboard-heavy admin workflows without pulling in jQuery.

Plugin contract

  • Progressive enhancement: keep a real select in the markup.
  • Plain JavaScript: Slim Select and Tom Select do not need a DOM helper library.
  • Token bridge: style generated containers with Windform CSS variables.
